# CineClip AI Studio (100% Tanpa API Key - Siap Deploy ke Vercel)

Aplikasi web pembuat rangkaian visual **Satu Konsep • Berbagai Tempat Berbeda** (hingga 30 scene) dari gambar referensi Anda.

## Cara Upload Langsung ke Vercel / GitHub
1. Ekstrak file ZIP ini di komputer Anda.
2. Upload seluruh isi folder `cineclip-ai-studio` ke repository GitHub baru Anda, atau jalankan lewat Vercel CLI / Drag & Drop.
3. Di Vercel, klik **Import Project** dari GitHub lalu klik **Deploy** (Vite akan otomatis terdeteksi).
4. Link Vercel Anda langsung bisa dibuka oleh siapa saja tanpa perlu memasukkan API Key.
